# 🐍 Snake Game - Mobile Fit Edition
**Desenvolvido por Welison** | *Engenharia de Software & Gestão de TI*

Este projeto é uma evolução do clássico "Jogo da Cobrinha", desenvolvido em **Python** com a biblioteca **Pygame**. O diferencial deste software é a interface adaptada para dispositivos touch e a persistência de dados local.

## 📱 Diferenciais do Projeto
* **Layout Mobile Fit:** Controles (D-Pad) agrupados no canto inferior para facilitar a jogabilidade em telas touch ou com uma única mão.
* **Persistência de Dados:** Implementação de sistema de recorde que salva a pontuação máxima em um arquivo local (`recorde.txt`).
* **Design UI/UX:** Interface limpa com botões arredondados, feedback visual de pausa e elementos gráficos personalizados (como os olhos da serpente).
* **Gestão de Código:** Projeto estruturado com foco em legibilidade e pronto para versionamento via Git.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Biblioteca Gráfica:** Pygame
* **Versionamento:** Git & GitHub

## ⌨️ Comandos e Atalhos
* **Setas (Tela):** Movimentam a cobra.
* **Tecla P:** Pausa/Despausa o jogo.
* **Tecla R:** Reseta o recorde gravado (limpa o arquivo local).
* **Barra de Espaço:** Reinicia o jogo após o Game Over.
